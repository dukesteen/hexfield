## Remaining release blockers

1. Enforce the signed takeover policy and implement certified offline/online
   observation; `never` must block protocol requests, not only hide a button.
2. Run a full recovered-game audit and explicit 2-/3-human no-release/resume
   traces.
3. Verify the implemented transfer destination route and return flow with a
   real two-device browser handoff, including old-key retirement.
4. Verify an everybody-left browser restart and measure resume latency.
5. Add the online history/outcome query path and the specified online
   save-import/read-only fallback.

No tests were run for this audit; the evidence above is taken from the linked
focused test/checkpoint records and current source paths.
