# Persistence lifecycle review disposition

This disposition compares the read-only review in [archived review](persistence-lifecycle-review-raw.json) with the current helper and fixture. It does not claim a full-game pass.

| Review finding                                                         | Current disposition                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Safety restore checked the session load instead of the controller load | Addressed. The wrapper observes the controller's actual `loadSafety` call and compares height, revision and bytes. It also checks the first subsequent write's original CAS revision. A full internal controller snapshot query is not exposed or needed for this profile.           |
| Continuation did not prove restored-peer participation                 | Addressed. A later command must match a non-nil precommit captured on a restored transport by sequence and entry hash. Periodic requires its one restored peer; everyone-left requires three distinct restored peers. The comparison does not depend on certificate subset identity. |
| Everyone-left had no closed interval or meaningful stagger             | Addressed in the trace. All sessions close, the virtual clock advances two seconds, then seats reopen in `[2, 0, 3, 1]` with 250 ms advances and flushes between reopenings. The artifact records the actual intervals.                                                              |
| Control or membership changes could escape the lifecycle gate          | Addressed. Terminal history rejects control and membership entries and certificates outside epoch 0.                                                                                                                                                                                 |
| Terminal boundary could fail and restart boundaries could drift        | Exact terminal-boundary completion is accepted. A boundary may be delayed while a command is pending, up to the existing 49-entry tolerance; skipping beyond that fails. Short games intentionally fail because they did not exercise the required rotations and everyone-left case. |
| Private-state equality relied on reconstruction determinism            | Addressed directly. Terminal reconstruction is checked against live per-seat hashes at each sequence. The independent audit separately compares deterministic reconstruction with the omniscient engine replay. Restore replay snapshots are counted exactly.                        |
| Lifecycle covered only quiescent restart points                        | Still scoped that way. It requires a shared head and no pending submission. In-flight write, send and acceptance interruptions remain with the separate focused persistence and fault fixtures.                                                                                      |
| Time limit and per-game input counts were missing                      | Addressed in the runner invocation and result. The CLI and CI job use a 900,000 ms limit; the result reports input counts by command/system type.                                                                                                                                    |
| Generic `faultInjected` field was false despite lifecycle restarts     | Clarified in the acceptance note. That field describes adversarial fault injection; lifecycle restarts are listed separately under `lifecycle.restarts`.                                                                                                                             |

The helper tests and scoped type checks pass, but no full persistence game has
completed. The policy gate remains open until a result artifact, source revision
and matching source manifest are retained.
