# Recovered-game v5 acceptance

The first seed-4 v5 attempt failed after 96.69 seconds at a retrospective private-slot assertion. That assertion inspected the owner's current hand after later certified commands could consume the card. The test now records private-slot visibility immediately after the certified `CARD_DEALT` commit. A focused engine test confirms that a legal `CLAIM_VICTORY` removes its private slot. The original failure log remains at `/private/tmp/hexfield-recovered-v5-audit.log`; it did not produce an artifact.

I reran the same seed once with the corrected assertion, unchanged card and dice derivation, the same 120-step/180-second limits, and the existing 3-VP acceptance target. The run passed in 95.42 seconds. Seat 0 was crashed before the three surviving sessions opened; recovery certified a seat-offline marker, authorization and activation. The game then certified setup, dice, trade, robbery, one development-card draw, and a terminal victory claim. The host submitted 42 game commands. All three surviving sessions reported complete audits with `ok: true`, `complete: true`, no missing seats, no history or input errors, no cheat findings, and no violations. The host's terminal/final head was sequence 70, hash `7358f375c67e36ce170ac8cd4440161cd46a3906852aa300753028c5c0f19d98`. The test did not separately record each peer's final head hash, so this note does not assert head equality beyond their complete audits.

The fixture uses real master-backed beacon and deck sources and the normal built-in verified protocol path. Its `ReplayPolicy` supplies success-only callbacks for exactly three extension points: `genesis.verifyCommitments`, `entry.verifySystem` and `entry.verifyCommand`. Thus this run does not independently test the commitment verifier delegated to `verifyCommitments`, any additional generic system-evidence verifier delegated to `verifySystem`, or additional application command restrictions delegated to `verifyCommand`. Built-in genesis shape/signature checks and mandatory protocol accounting, hand/deck/crypto and consensus checks remain in the ordinary path. It uses a 3-VP target to keep the recovered full-game trace bounded, not the default 10-VP release target. The test's certified first draw was decoded by its owner at the deal commit, before any later claim could remove that slot.
