# Fixed-H hidden-transfer precomputation

The eight-type Node diagnostic used the retained script `/private/tmp/hexfield-hidden-fixedbases.mjs` with one warmup and three samples per variant on Darwin arm64, Node v25.9.0. Without an H table, median prove/verify were 500.6/351.9 ms. Calling `H.precompute(8, false)` once reduced them to 316.0/235.3 ms; setup cost 22.6 ms. Precomputing G as well gave 318.5/232.8 ms, so production precomputes H only. Raw outputs are `/private/tmp/hexfield-hidden-fixedbases-{NONE,H8,GH8}.json`. These are Node diagnostics, not a Chromium acceptance result; the prior Chrome worker sample was 757–868 ms prove plus 400–449 ms verify without this change.

Installed `@noble/curves@2.4.0` uses `Point.precompute` to set a point's window size and build its reusable table (`abstract/edwards.js:179–183`, Ristretto wrapper `:482–486`). Ristretto `multiply` still calls Edwards `multiply` (`:470–471`); Edwards `multiply` calls `wnaf.mulSecret` (`:281–289`), whose cached path is constant-time (`abstract/curve.js:360–382`, `:466–490`). `scalePoint` still calls `point.multiply` for nonzero secret scalars. No `multiplyUnsafe` call or proof encoding changed. The eight-type proof's canonical hash remains the pre-change value `b1e86a98ef84995fee4601548728a63045e165d999447a77fd1fd7b201eb573a`.

The fresh-server Chrome worker run on 2026-09-27 measured **1,091.8–1,142.0 ms combined** across three valid proofs. Proving took 744.8–810.1 ms and verification 326.8–372.6 ms.
